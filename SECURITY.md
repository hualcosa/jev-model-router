# Security policy

Do not open a public issue containing secrets, raw task text, credentials or a
security-sensitive reproducer. Use the repository’s GitHub **Security → Report a
vulnerability** flow if it is available. If private reporting is unavailable,
request a private contact channel without publishing exploit details. This fork
does not promise a response-time SLA or treat the upstream maintainer as its
security contact.

A useful private report includes the affected revision/runtime version, a minimal
synthetic reproducer, impact and any relevant configuration with secrets removed.

Automatic routing is not an authorization boundary. Jev receives a minimized
task description when consent permits; minimization does not guarantee anonymity.
Keep keys and state outside Git, preview outbound data, and do not grant broader
permissions to work around an abstention. See [configuration](docs/configuration.md).
